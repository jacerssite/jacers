# Jacer music credits

The built-in `Original` track is generated in-browser by Jacer.

The selectable downloaded tracks are CC0 works sourced from OpenGameArt:

- `out-in-space.ogg` — “Out in Space” by Agecaf: https://opengameart.org/content/out-in-space-0
- `space-adventure.ogg` — “Space Adventure” by MintoDog: https://opengameart.org/content/space-adventure
- `out-there.ogg` — “Space Music: Out There” by yd: https://opengameart.org/content/space-music-out-there
- `crazy-space.ogg` — “Crazy Space” by rubberduck: https://opengameart.org/content/crazy-space
- `spacelife-14.ogg` — “Spacelife #14” by yd: https://opengameart.org/content/spacelife-14

Each source page identifies the corresponding work as CC0. This file is kept with the assets so the source and license history remains easy to audit.
